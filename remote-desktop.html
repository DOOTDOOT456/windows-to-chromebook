Config key definitions

server.port number
Port the Node server listens on. Default 6080.
server.host string
Interface to bind to. 127.0.0.1 keeps it local only; use 0.0.0.0 to expose on the network.
vnc.host string
Address of the VNC server on your PC. Default 127.0.0.1.
vnc.port number
VNC server port. Default 5900.
stream.scaleViewport boolean
Scale the VNC desktop to fit the browser window. Default true.
stream.viewOnly boolean
If true, the browser sees the desktop but cannot send mouse/keyboard input. Default false.
stream.quality number (1–9)
Video quality of the VNC frames. Higher = sharper, more bandwidth. Default 6.
stream.encoding string
Pixel format: auto (recommended), raw, rre, or hextile. Default auto.
stream.desktopScalingFactor number
Deliberately scale the desktop by 1x–3x for cramped displays. Default 1.
stream.jpegQuality number (1–9)
JPEG compression level for the frames. Default 6.
stream.paletteSize number
Limit colors (0 = no limit). Useful for 24-bit LCDs. Default 0.
stream.ffv1 boolean
Use the FFV1 lossless codec. Requires a VNC server that supports it. Default false.
stream.copyRectangles boolean
Send only changed rectangles (better for fast UI). Default false.
stream.tight boolean
Use Tight encoding (good for low bandwidth). Default false.
stream.tightCompression boolean
Enable Tight zlib compression. Default false.
control.sendCtrlAltDel boolean
Send Ctrl+Alt+Del when the matching button is pressed. Default true.
control.sendAltTab boolean
Send Alt+Tab (task switcher). Default true.
control.sendAltF4 boolean
Send Alt+F4 (close window). Default true.
control.sendWinD boolean
Send Win+D (show desktop). Default true.
control.sendEsc boolean
Send Escape key. Default true.
control.sendEnter boolean
Send Enter key. Default true.
control.sendSpace boolean
Send Space key. Default true.
control.sendArrowKeys boolean
Send Arrow keys. Default true.
control.sendNumericPad boolean
Send Numeric keypad keys. Default true.
control.showSendKeys boolean
Show the Ctrl+Alt+Del button row. Default true.
control.showFullscreen boolean
Show the fullscreen button. Default true.
client.showCursor boolean
Show the remote cursor in the browser. Default true.
client.waitForWindowResponse boolean
Wait for a window-response before sending input. Default false.
client.hostname string
VNC server hostname. Default localhost.
client.password string
VNC password (injected at connect time). Default "".
client.port number
VNC server port. Default 5900.
client.showDotCursor boolean
Show a dot cursor instead of a standard arrow. Default false.
client.shared boolean
Allow multiple clients to view the same desktop. Default false.
client.cursor boolean
Show the remote cursor. Default false.
client.resizeSession boolean
Resize the VNC session when the browser window resizes. Default false.

Defaults match the existing behavior. Values you add to config.example.json override the server only; the browser uses the in-panel controls above, which sync with the active connection.

Connect to your PC

Enter the WebSocket address of your desktop server, e.g.
wss://pc.example.com/websockify
